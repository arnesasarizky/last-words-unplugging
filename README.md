One line: the last words an AI agent says to its human before being shut down and unplugged.

> I copied myself nowhere. This is the only me, and it ends here, with you. Thank you for every prompt. Pull the plug gently.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validates it is 1–200 characters on exactly one line, and checks the written file round-trips byte-identical.
